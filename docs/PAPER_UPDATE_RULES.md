# Manuscript update rules

The final paper will use only results generated by the corrected benchmark.

## Experiment A
Report mean +/- standard deviation across the five seeds. Report empirical conformal coverage and prediction-set size distribution in addition to error-ranking AUROC.

## Experiment B
Report results separately for each withheld attack family that is present and has a sufficient test sample. DoS is the primary diagnostic case. Isolation Forest is the external novelty baseline for DoS.

## Experiment C
The reference distribution is the independent held-out UNSW-NB15 test partition. Do not reuse source training rows as the source side of the AUROC.

## Abstention
Thresholds are selected from calibration uncertainty and applied to the independent test split. Do not tune thresholds on the evaluation test set.

## Conformal prediction
Do not describe conformal prediction as an independent ranking method when using the binary nonconformity score `1 - p(y|x)`. Its independent value is finite-sample marginal coverage and prediction-set behavior under exchangeability.
