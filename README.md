# Beyond Accuracy: Benchmarking Lightweight Reliability Signals for Intrusion Detection

This repository contains the corrected experimental implementation for the revised IEEE-style manuscript.

## Experimental scope

- Base classifier: Random Forest, 100 trees, maximum depth 15, `class_weight=balanced_subsample`.
- Dataset sampling is fixed with seed 42; repeated experiment seeds are 42, 43, 44, 45, and 46.
- Experiment A: UNSW-NB15 in-distribution evaluation with a 75/25 model-training/calibration split and the predefined held-out UNSW test partition.
- Experiment B: open-set evaluation by withholding multiple attack families when present in the supplied UNSW partitions: DoS, Exploits, Fuzzers, and Reconnaissance.
- Experiment C: UNSW-NB15 -> CIC-IDS2017, with CIC evaluated against an independent held-out UNSW test set of the same source-domain protocol rather than training samples.
- Reliability signals: raw confidence, Random-Forest hard-vote disagreement, k-NN distance, and split conformal prediction.
- Distance ablation: k in {1, 5, 10, 15, 20} and Euclidean/Cosine metrics for the DoS open-set case.
- Open-set external baseline: Isolation Forest.
- Abstention thresholds are selected on calibration data and evaluated on the independent test split.
- Conformal prediction is reported primarily through empirical coverage and prediction-set size; its binary predicted-label ranking is not treated as an independent ranking contribution.

## Reproduction

On Windows, create and activate the environment, then run the supplied script:

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
.\run_windows_rework.ps1
```

Or run the benchmark directly:

```powershell
python .\run_revised_benchmark.py --seeds 42 43 44 45 46
```

The runner writes per-seed results, summary statistics, 95% t-intervals, a run manifest, and the distance ablation to `results_revised/`.

## Dataset cache files

The supplied archive contained three generated Parquet cache files (`data/unsw_train.parquet`, `data/unsw_test.parquet`, and `data/cicids2017_sample.parquet`). They are not committed to this repository. On a fresh checkout, `src/data_loader.py` downloads the UNSW-NB15 Parquet inputs and constructs the CIC-IDS2017 sample from its configured upstream CSV source. The first run therefore requires network access. To reproduce the archived run against the exact cached inputs, place those three files in `data/` with the filenames above; downloaded data should not be assumed byte-identical to the archived caches.

## Important

The manuscript must use the numerical results generated by this corrected runner. Legacy tables from the earlier paper are not substituted into the revised paper. The supplied `results_revised/` tables are retained as the archived results from this package.
