# Run the corrected benchmark

Use Python 3.12 and run these commands from the repository root on Windows PowerShell:

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
.\run_windows_rework.ps1
```

Alternatively, run the benchmark directly:

```powershell
python .\run_revised_benchmark.py --seeds 42 43 44 45 46
```

The corrected benchmark writes new evidence to `results_revised/`. On a fresh checkout, required data caches are downloaded or generated by `src/data_loader.py`; the first run requires network access. See `data/README.md` for the archived cache filenames and exact-input reproduction note.

Do not copy the old `results/*.csv` values into the revised manuscript. The revised paper must use the values generated by `results_revised/`.
